Ember — предварительная версия для Windows 10/11 x64

Установите Ember-Setup.exe и запустите ярлык Ember.
Python и .NET отдельно не требуются. Millennium необязателен.
После установки Ember подключается при обычном запуске Steam.
Фоновый процесс не запускает Steam при входе в Windows и не открывает окно Ember.
Перед обновлением закройте Ember; перед удалением его адаптера закройте Steam.

Без Millennium первый запуск может штатно перезапустить Steam с параметром
CEF debugging. Активную игру Ember не закрывает.
При установленном Millennium Ember открывается страницей внутри Steam.

Библиотека Ember управляет регистрациями добавленных игр. «Удалить из Ember»
сохраняет игровые файлы и сохранения. Регистрацию можно восстановить.
Скачивание и запуск выполняются через обычный Steam.

LumaCore и сторонние бинарные инструменты в этот пакет не входят.
Для зависимых от них функций нужен совместимый компонент; наличие Ember
само по себе не гарантирует поддержку любой игры. SmokeAPI загружается
по запросу из своего источника. Не все игры поддерживают инструменты DLC.

Настройки и журналы: %LOCALAPPDATA%\Ember\Desktop.
Stop Ember в меню «Пуск» останавливает службу.
Удаление приложения сохраняет игры, сохранения и пользовательские данные.
